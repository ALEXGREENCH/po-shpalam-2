ПО ШПАЛАМ 2 — НЕЙРОСЕТИ ЗАМЕНЯЮТ ПРОГРАММИСТОВ
Выпуск 01

Откройте index.html в современном браузере. Папка работает офлайн без fetch.
Это демонстрационная версия с записанным текстом и частичной озвучкой.
Текстовая часть выпуска готова: 56 реплик — 14 в новостях и 42 в основной теме.
Озвучено 20 из 56 реплик; проверенная сумма этих записей — 15 минут 36,909 секунды.
Все доступные текстовые реплики можно прочитать; звук подключён только для
проверенных записей. Число реплик, число озвученных реплик и суммарное
проверенное время доступного аудио показаны на стартовом экране.
Получение остальных аудиозаписей остановилось на дневном лимите Character.AI.
Продолжительность всего выпуска пока не подтверждена; 40 минут — цель,
а не длительность этой версии. Реплики без аудио остаются текстовыми.

Если messages пуст, показывается экран подготовки: записанного выпуска нет,
а подтверждённая длительность неизвестна. Заглушек под реплики нет.

Целевой объём: 10 минут новости AI и 30 минут главная тема.
Цель 40 минут не считается выполненной по количеству текста или таймеру UI.
WAV проверяется по числу кадров и частоте дискретизации. У других форматов,
пока нет измерения декодером, duration_seconds остаётся null. Длительность,
присланная вручную во входном JSON, не принимается за измерение.

Данные
source.schema.json — схема входа и опубликованного source.json.
source.json — оригинальные raw-ответы, редакционные display, переданный prompt
и ссылки source_url; они не дописываются движком.
data.js — подготовленные данные для офлайн-показа display.
editorial_note — необязательная проверка факта. Показывается отдельной
сворачиваемой заметкой в кадре и истории; не меняет речь и не озвучивается.

В рабочем проекте скрипт work/build_episode1.py читает
work/episode1-dialogue.json. Если файла нет, собирает пустой источник.
Не переносит реплики из старого выпуска. Старую демку не меняет.

Аудио
Файл в message.audio.file задаётся относительно assets/audio/ этого выпуска.
Допускаются только существующие локальные файлы, внутри этой папки,
с проверенной сигнатурой WAV, MP3, OGG, M4A/MP4 или WebM.
Для подключения требуется audio.moderated=true: редактор проверяет, что
аудиозапись соответствует публикуемой редакционной речи.
Кнопки звука видны только при наличии файлов. Озвучка не синтезируется.
Выпуск не содержит внешнего рассказчика и выбора реплик.

Просмотр готовой записи
Пробел / вправо — далее. Влево — назад. Esc — меню.
История, темы, настройки чтения, полноэкранный режим, сохранение позиции.
Автопоказ ждёт окончания воспроизведения. Без аудио используется заданная
пауза чтения; она не входит в измерение длительности выпуска.
Если браузер не разрешает localStorage, можно скачать файл закладки.

Маркировка
Это фанатские / пародийные AI-боты Character.AI. Их реплики не являются
реальными высказываниями людей. Все source URL/prompt/raw/display сохраняют
происхождение записи; raw может отличаться от редакционного display.

Публичный экспорт
Список разрешённых файлов находится в public-export.json.
Архив собирается скриптом work/package_episode1.py после финальной сборки.
В ZIP входят только перечисленные файлы, изображения и одобренные аудио,
которые действительно подключены к кадрам data.js и проверены по source.json.
production.html, capture.html и capture.js — локальные служебные страницы.
Они, рабочие файлы и неподключённые аудиозаписи в публичный ZIP не входят.

Локальные изображения повторно использованы из предыдущей демки.
В веб-версии изображения сохранены в WebP; старые аудиодорожки в этот выпуск не копировались.

Версия для GitHub Pages
Изображения преобразованы в WebP, одобренные WAV — в MP3.
Речь, скорость и последовательность сохранены. Длительность проверена
по декодированным MP3; source_master сохраняет данные одобренного WAV.
